Setup and compatibility

Open Lantern and connect your TV first. Install the Firefox bridge using the setup script included with Lantern. After loading this extension, reload the video page once.

This build supports HTTPS HLS and MP4 streams. Keep Lantern running and the laptop awake. Keep this tab open for session updates; paused players may need restarting if access expires. Ads inserted into the video can remain.

The extension needs access to HTTPS requests to find video inside embedded players and CDN hosts. Detected URLs and required request headers stay in memory on this computer; the extension does not save browsing history or send data to a cloud service.
